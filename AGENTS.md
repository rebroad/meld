# Repository instructions

- After any modification in this repository, build and install Meld before considering the work complete. Sync the checkout to the `../meld.build` sibling symlink with `cpto`, run `MELD_BUILD_DIR=../meld.build/_build-from-source ./build.sh`, then install with `sudo ninja -C ../meld.build/_build-from-source install`.
- Confirm the installed Meld is the build from this checkout before reporting completion.
